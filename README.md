# Herbify-Website
Herbify is a modern, fully responsive React + Tailwind CSS website that showcases herbal and organic wellness products.
It includes smooth animations (Framer Motion), 3D-like effects, background drops, testimonials, and a clean contact section.

🔗 Live Demo: https://herbify-web.netlify.app/

✨ Features

🌱 Hero Section with zoom background & animated leaves
💧 Products Section with floating oil drops effect
💬 Testimonials auto-scrolling with smooth animations
📩 Contact Form with social media links & icons
🌍 Fully responsive design (mobile, tablet, desktop)
🎨 Styled using Tailwind CSS
🎥 Animated using Framer Motion

🛠️ Tech Stack
React (Create React App)
Tailwind CSS for styling
Framer Motion for animations
React Icons for social icons
